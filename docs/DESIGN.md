# Design and limits

One input handle is read into bounded memory, hashed as exact bytes, decoded as strict UTF-8, then parsed line by line. JSON properties are strict and case-sensitive; duplicated names including escaped names, unknown fields, duplicate IDs, invalid numbers/labels and malformed JSON fail before any report is written. Input hashes include BOM and whitespace. No model, prediction text, or individual IDs are included in the report.

With `B` equal-width bins, `floor(p*B)` selects a bin and `p=1` is assigned to the last. Each bin reports bounds, whether its upper bound is inclusive, support, positives and nullable averages. Brier is the average squared probability error. ECE is `sum((bin count / N) * abs(bin mean probability - bin positive rate))`. Empty bins contribute zero and expose null averages. Report schema version 1, exit codes, and these formulae are the contract.

For `compare`, each input is validated independently and kept in memory. Their case-sensitive ID sets and boolean labels must match, regardless of row order. Reports are computed only after matching, with differences defined as candidate minus reference. Aggregated bins are based on each file's own predictions; they are not a per-row difference or a significance test. Neither IDs nor individual probabilities are emitted.

Bounds per input: 32 MiB file bytes, 100,000 rows, 1 Mi UTF-16 characters per line, ID length 256 and JSON depth 8. Memory includes decoded input and validated rows; comparison holds both inputs. These are workload limits, not a sandbox for hostile files; external resource/time limits are appropriate. Input reads are not an atomic snapshot if files change concurrently. Reports are on stdout; the shell controls redirection and output-file safety.

Binning loses individual information and ECE changes with bin choice; finite sample error and dataset selection matter. The sample demonstrates cancellation. Brier combines calibration and discrimination, so no single metric proves calibration. Preserve the held-out data, model version, generation settings and sampling plan outside this tool; it cannot verify those claims.
